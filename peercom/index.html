Données et confidentialité

Mode anonyme
Masque votre identité aux pairs. Votre pseudonyme apparaît comme « Anonyme ».
Partager le statut en ligne
Permet aux pairs de voir votre statut (en ligne, absent, ne pas déranger).

Sécurité

Toutes les conversations PeerCom sont chiffrées de bout en bout avec ECDH P-256 + AES-256-GCM.
Conservation locale des discussions
Sauvegarde les messages sur votre appareil. Pour les DMs, la personne avec qui vous parlez doit également activer ce paramètre. Pour les groupes, tous les membres doivent l'activer. Ce paramètre est actif par défaut pour les serveurs.
Le pair distant n'a pas encore activé la conservation locale. Les messages ne seront pas conservés pour cette conversation.
Effacer les données locales
Supprime tous les messages, contacts et paramètres stockés localement.
