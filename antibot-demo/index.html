Comment fonctionne le score ?
  • Départ à 100 pts — des points sont déduits selon les signaux suspects.
  • Honeypot rempli : -80 pts (piège invisible pour les bots).
  • Webdriver / headless détecté : -35 pts.
  • Chaque indice headless supplémentaire : -12 pts (plafonné à -40).
  • Absence de mouvement souris (ni tactile, ni scroll) : -25 pts.
  • Mouvements trop linéaires ou vitesse constante : jusqu'à -25 pts.
  • ≥ 70 → humain · 40-69 → suspect · < 40 → bot
