# SPDX licenses directory

Ce dossier contient les textes complets des licences référencées dans les
en-têtes des fichiers source via leur identifiant SPDX (champ
`SPDX-License-Identifier`).

Chaque fichier porte le nom exact de l'identifiant SPDX qu'il représente,
suivi de l'extension `.txt`, conformément à la spécification SPDX et à la
convention [REUSE](https://reuse.software/spec/).

> Le préfixe `LicenseRef-` indique une licence personnalisée (non incluse dans
> la liste officielle SPDX). Sa définition se trouve donc dans ce dossier.
