🔐 Politique de Confidentialité

1. Introduction

VentiStudio respecte votre vie privée et s'engage à protéger vos données personnelles. Cette politique explique comment nous collectons, utilisons et protégeons vos informations.

2. Données Collectées

Nous collectons uniquement les données que vous nous fournissez volontairement :

  • Nom et adresse email (via le formulaire de contact)
  • Sujet et message (via le formulaire de contact)
  • Données de navigation (cookies, localStorage)

3. Utilisation des Données

Vos données sont utilisées pour :

  • Répondre à vos demandes de contact
  • Améliorer notre site web
  • Analyser les performances (analytics)
  • Personnaliser votre expérience

4. Protection des Données

Nous utilisons :

  • HTTPS/SSL pour chiffrer les communications
  • Headers de sécurité (CSP, X-Frame-Options, etc.)
  • Validation des formulaires
  • Pas de stockage de données sensibles

5. Cookies

Nous utilisons des cookies non-invasifs pour :

  • Mémoriser votre préférence de thème (localStorage)
  • Améliorer votre expérience utilisateur
  • Analyser les performances du site

6. Vos Droits

Vous avez le droit de :

  • Accéder à vos données personnelles
  • Demander la suppression de vos données
  • Refuser les cookies non-essentiels
  • Nous contacter pour toute question

7. Contact

Pour toute question sur cette politique :

  • Email: privacy@ventistudio.fr
  • Discord: https://discord.gg/ventistudio
  • Web: https://ventistudio.fr/contact
