📦 API Documentation

Endpoints complets pour gérer VentiStudio programmatiquement

GET /api/pages

Lister toutes les pages publiées

curl https://api.ventistudio.fr/pages \
  -H "Authorization: Bearer YOUR_TOKEN"
POST /api/pages

Créer une nouvelle page

curl -X POST https://api.ventistudio.fr/pages \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"title": "Page", "slug": "/page", "content": "..."}'
PUT /api/pages/:id

Mettre à jour une page existante

curl -X PUT https://api.ventistudio.fr/pages/123 \
  -H "Authorization: Bearer YOUR_TOKEN"
DELETE /api/pages/:id

Supprimer une page

curl -X DELETE https://api.ventistudio.fr/pages/123 \
  -H "Authorization: Bearer YOUR_TOKEN"
POST /api/blog

Créer un nouvel article blog

{
  "title": "Article Title",
  "author": "Author Name",
  "content": "...",
  "tags": ["tag1", "tag2"],
  "published": true
}
POST /api/alerts

Créer une alerte

{
  "title": "Alert Title",
  "message": "Alert message",
  "level": "danger",
  "duration": 5
}
