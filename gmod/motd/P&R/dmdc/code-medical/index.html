Code Médical Radio

Codes utilisables en radio : Aile Médicale (Quartier Médical)

⚠️ Attention : Ces codes s'appliquent uniquement dans l'aile médicale (Quartier Médical : QM), sauf indication contraire.

Code Bleu : Arrêt Cardiaque / Détresse Médicale

Arrêt cardiaque ou détresse médicale nécessitant une réanimation.

QM Uniquement

Code Rouge : Incendie

Incendie déclaré dans l'aile médicale.

QM Uniquement

Code Jaune : Catastrophe Interne ou Externe

Catastrophe interne ou externe affectant le quartier médical.

QM Uniquement

Code Noir : Menace de Bombe

Menace de bombe signalée dans ou à proximité de l'aile médicale.

QM Uniquement

Code Orange : Déversement NRBC

Déversement de matières dangereuses « NRBC » (Nucléaire, Radiologique, Biologique, Chimique).

QM Uniquement

Code Argent : Personne Armée / Prise d'Otage

Personne armée ou prise d'otage dans l'aile médicale.

QM Uniquement

Code Violet : Personne Violente

Personne violente nécessitant une intervention dans le quartier médical.

QM Uniquement

Code Rose : Enlèvement

Enlèvement signalé dans l'aile médicale.

QM Uniquement

Code Vert : Contaminant Biologique Anormal

Brèche de sécurité liée à un agent biologique ou infectieux anormal. Le département médical obtient autorité complète.

Autorité Médicale Complète

Code Super-Vert : Verdict Thanatovirus

Contaminant biologique extrême, potentiellement cognitif ou mémétique. Le département médical prend le contrôle total.

Contrôle Total Médical
