Codes Couleurs de la Fondation SCP

Version Complète : The Lost Site

⚠️ Notice : Chaque code standard possède une variante « Super » désignant une version extrême de la menace. Les codes Super indiquent une escalade critique nécessitant des mesures exceptionnelles.

■ Code Ambre : Menace Mémétique / Cognitive / Info-hasardeuse

Apparition ou brèche d'un agent informationnel affectant la cognition, la perception ou la mémoire.

Directive : Éviter toute interaction verbale ou sensorielle, rester silencieux, fermer les yeux et oreilles, attendre les ordres de la sécurité.

■■ Code Super-Ambre : Réalité Infectée Cognitivement

Brèche d'un agent info-cognitif à propagation virale affectant les consciences collectives.

Directive : Évacuation cognitive, désactivation de systèmes informatiques connectés, isolement individuel obligatoire.

■ Code Bleu : Objet Intelligent Mineur en Mouvance

Rupture de confinement d'un objet intelligent mais moins qu'un humain.

Directive : Suivre les consignes des équipes de sécurité et rejoindre un lieu sûr.

■■ Code Super-Bleu : Objet Intelligent Majeur en Mouvance

Brèche d'un objet anormal aussi intelligent, voire plus, qu'un humain.

Directive : Même procédure que pour le Code Bleu, avec une vigilance accrue.

■ Code Vert : Contaminant Biologique Anormal

Brèche de sécurité liée à un agent biologique ou infectieux anormal.

Directive : S'équiper de tenues de protection. Aucune évacuation. Le département médical obtient autorité complète.

■■ Code Super-Vert : Verdict Thanatovirus

Contaminant biologique extrême, potentiellement cognitif ou mémétique.

Directive : Évacuation massive obligatoire. Exécution autorisée pour tout personnel contaminé. Le département médical prend le contrôle total. Les zones infectées peuvent être verrouillées ou détruites.

■ Code Rouge : AGE, Agresseur de Grande Envergure

Rupture de confinement d'un SCP extrêmement destructeur (ex. SCP-682).

Directive : Évacuation vers un abri immédiate. Une F.I.M. de grande taille est déployée.

■■ Code Super-Rouge : Multiples AGEs / Guerre SCP

Ruptures multiples de plusieurs AGEs simultanément.

Directive : Priorité absolue à la survie des sites primaires. Ordre d'évacuation globale ou auto-destruction si confinement impossible.

■ Code Noir : MNR, Menace Non Révocable

Rupture d'un SCP inarrêtable (ex. SCP-096).

Directive : Rejoindre un abri sans tenter d'interagir. Ne pas engager sauf pour ralentir l'entité.

■■ Code Super-Noir : MNR Systémiques

Brèche d'entités de classe MNR à action en chaîne inter-site.

Directive : Aucun confinement ni ralentissement possible. Tout système passe en mode d'autonomie de survie maximale.

■ Code Blanc : Assaut Externe Structuré

Attaque externe organisée sur l'installation.

Directive : Tous les accès doivent être verrouillés. La sécurité doit éviter les affrontements. Intervention F.I.M. prévue.

■■ Code Super-Blanc : Coalition Hostile Globale

Attaque coordonnée mondiale de plusieurs groupes d'intérêt contre les sites SCP.

Directive : Tous les sites passent en mode Siège. Coordination militaire internationale requise.

■ Code Gris : Menace Interne / Émeute

Intrusion interne, émeute de classe D ou sabotage.

Directive : Procédures identiques au Code Blanc. Contient les menaces provenant du site lui-même.

■■ Code Super-Gris : Insurrection Totale

Rébellion totale du personnel ou prise de contrôle du Site par une force interne organisée.

Directive : Exécution autorisée des entités hostiles internes. Réinitialisation du protocole de commandement.

■ Code Magenta : Altération Réalité / Spatio-temporelle

Brèche liée à une entité ou anomalie brisant les lois fondamentales de la réalité.

Directive : Repli dans un abri recommandé, sauf si inefficace face à l'anomalie.

■■ Code Super-Magenta : Déstructuration Universelle

La structure même de la réalité ou du continuum espace-temps est compromise.

Directive : Activation des systèmes de secours dimensionnels si existants. Préparation à l'effondrement local de l'univers connu.

■ Code Vide : Menace Non Décrite

Menace inconnue non encore catégorisée.

Directive : Suivre les instructions des unités de sécurité.

■■ Code Super-Vide : Menace Indéfinissable

Menace au-delà de la compréhension ou de la description.

Directive : Aucune procédure spécifique. Suivre les ordres de sécurité.

■ Code Argent Froid : Effondrement Systémique

Événement fatal à la structure organisationnelle de la Fondation.

Directive : Préparation à la liquidation du département concerné. Aucune durée estimable.

■■ Code Super-Argent Froid : Extinction Organisationnelle

La Fondation ne peut plus fonctionner à aucune échelle.

Directive : Annonce de la fin de l'autorité centrale. Transfert des missions vers des groupes de survie régionaux ou autonomes.

■ Code Gange : Infestation Massive

Infestation incontrôlable d'un secteur. L'entretien conventionnel est inefficace.

Directive : Déploiement des équipes de décontamination obligatoire.

■■ Code Super-Gange : Purulence Totale

Infestation ou corruption organique affectant l'ensemble de l'installation.

Directive : Requiert le confinement par incendie contrôlé, explosion, ou scellage du site.
