ZoneRetributionRP

Nom : ZoneRetributionRP

Type : Jeux

Origine : SCP:LS

Créateur : Hikari Umaishi, Reivun (DJMRS3RKILER)

Statut : Actif

Description

ZoneRetributionRP est un serveur de jeux basé sur le jeu SCP:LS, qui se déroule dans la Zone de Retribution Oméga 98.

Le serveur est conçu pour offrir une expérience immersive et réaliste aux joueurs, avec des éléments de jeu de rôle et de survie.
