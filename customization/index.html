Vos Préférences & Données

Consultez, comprenez et gérez toutes les données que VentiStudio stocke localement dans votre navigateur. Tout reste sur votre appareil : nous ne les envoyons jamais à nos serveurs.

Comment ça fonctionne

Tout est stocké localement

VentiStudio n'utilise pas de cookies serveur ni de pistage. Toutes vos préférences et données sont stockées grâce aux mécanismes intégrés de votre navigateur :

  • localStorage : Données persistantes qui restent jusqu'à ce que vous les supprimiez manuellement. Utilisé pour les préférences de thème, la progression des easter eggs, l'historique de recherche, les données de newsletter, etc.
  • sessionStorage : Données temporaires automatiquement supprimées lorsque vous fermez l'onglet. Utilisé pour les jetons d'accès de session (ex. : accès Gold).

Cela signifie que vos données ne quittent jamais votre appareil. Nous n'y avons pas accès, ne pouvons pas les récupérer et ne les sauvegardons pas. Vous avez le contrôle total.

Zone de danger

Cette action est irréversible. Cliquer sur « Supprimer toutes les données » effacera définitivement toutes les données que VentiStudio a stockées dans votre navigateur : y compris vos préférences de thème, la progression des easter eggs, l'historique de recherche, les sauvegardes automatiques de Suite, et toutes les autres entrées listées ci-dessus.

Nous ne fournissons aucune assistance pour la récupération de données. Puisque toutes les données sont stockées localement dans votre navigateur, nous n'avons aucun moyen de les restaurer une fois supprimées. Ne continuez que si vous êtes absolument certain(e).
